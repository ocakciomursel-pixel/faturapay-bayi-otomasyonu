# FaturaPay & KontörMatik Kurumsal — TL Yükleme, Fatura Tahsilat & Alt Bayi Otomasyonu

Canlı İnteraktif Web & Mobil Demo: **https://ocakciomursel-pixel.github.io/faturapay-bayi-otomasyonu/**

## Temel Modüller
- **GSM TL & Paket Yükleme Terminali:** Turkcell, Vodafone, Türk Telekom tam TL ve ses/internet paket yükleme, otomatik bayi iskonto ve anlık net kâr hesaplama, resmi PDF/fiş dekont çıktısı.
- **Kurum Fatura Sorgulama & Online Tahsilat:** Elektrik, Su, Doğalgaz, İnternet/TV kurumları online borç sorgulama, hizmet bedeli/komisyon tanımlama ve anlık API kapama.
- **Alt Bayilik & Cari Muhasebe Yönetimi:** Sınırsız alt bayi açma, bayi gruplarına göre (Standart / Gold / Ana Dağıtıcı) özel komisyon tanımlama, veritabanı satır kilitli (InnoDB Row-Lock) mükerrer çekim önleyici cari kasa.
- **Sanal POS & 7/24 FAST Otomasyonu:** PayTR, Param POS ve iyzico 3D Secure HMAC-SHA256 callback doğrulamalı otomatik bakiye yükleme + banka havale/FAST bildirim onay ekranı.
